# online_qa
# 在线问答系统（Online QA System）

## 项目简介

在线问答系统是一个基于前后端分离架构开发的问答平台。

用户可以在系统中发布问题、查看问题列表、进入问题详情、提交回答。
系统使用 MySQL 负责业务数据持久化存储，同时结合 Redis 实现数据缓存，提高系统访问效率。

本项目主要用于学习和实践：

- 前后端分离开发
- RESTful API设计
- FastAPI后端开发
- Vue前端开发
- MySQL数据库设计
- Redis缓存应用
- SQLAlchemy ORM数据操作

| 技术 | 说明 |
|-|-|

| 技术 | 说明 |

# 系统功能


## 用户功能

- 用户注册
- 用户登录
- 用户信息管理


## 问答功能

### 问题管理

支持：

- 发布问题
- 查看问题列表
- 查看问题详情
- 修改问题
- 删除问题


### 回答管理

支持：

- 提交回答
- 查看问题回答
- 自动统计回答数量


### 缓存功能

使用 Redis 缓存：

- 问题列表数据
- 热点访问数据
